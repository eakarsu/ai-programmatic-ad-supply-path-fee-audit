# Programmatic Ad Supply-Path Fee Audit

Expose programmatic fee leakage and optimize supply paths through impression-level bid, clearing-price, and intermediary reconciliation.

**Primary buyer:** Brands, publishers, and media agencies. **Evidence:** insertion orders, DSP logs, SSP logs, bid requests, impressions, clearing prices, tech fees, data fees, verification, invalid traffic, invoices, and payments.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Insertion order library
- Campaign creative registry
- DSP log ingestion
- SSP log ingestion
- Bid request matching
- Impression event matching
- Clearing price reconstruction
- DSP fee calculation
- SSP fee calculation
- Data fee audit
- Verification fee audit
- Invalid traffic adjustment
- Invoice reconciliation
- Supply-path exception workflow
- Campaign publisher analytics

Run `./start.sh`, then open <http://127.0.0.1:4730>. API: `5730`.
